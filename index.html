Conectar ao HY300 (IP ou Bluetooth)

Escolha conectar diretamente pelo endereço IP na rede Wi-Fi ou via Bluetooth — sem script ponte ADB.

Como funciona sem ADB: Na pré-visualização, os comandos rodam em modo simulado. Para controlar o HY300 real via IP sem ADB, instale no projetor um receptor Wi-Fi como TranScreen ou Android TV Remote Service e informe o IP do projetor abaixo.
Projetores salvos (IP)
Pareamento Bluetooth: Usa a API Web Bluetooth do navegador (Chrome/Edge no Android, Windows e macOS) para buscar dispositivos BLE próximos. No iPhone/iPad (Safari), o navegador não libera Bluetooth diretamente — nesse caso use o modo Wi-Fi IP ou um app nativo Bluetooth HID.

Pronto para buscar projetor HY300 via Bluetooth
Desconectado
  1. No projetor HY300, abra Configurações → Bluetooth e deixe o Bluetooth ativado.
  2. Clique em Buscar Dispositivo Bluetooth acima (no Chrome/Edge) e selecione o HY300 na lista.
  3. Se o navegador bloquear o Bluetooth ou estiver no iOS, use a aba Wi-Fi (IP Direto) acima.
